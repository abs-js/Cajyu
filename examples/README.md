# Examples

Only one project: **Orgapp Auth**

File: `orgapp-auth.cjy`

A small app with registration, login, profile, posts and token authentication using Orgapp + Auth + Cache.

### Install

```bash
cajyu inst Orgapp
cajyu inst auth
cajyu inst cache
cajyu inst serial
```

### Run

```bash
cajyu run examples/orgapp-auth.cjy
```
