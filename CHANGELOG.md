# Changelog

## 1.2.2
- `const` for immutable variables
- `try` / `catch` with special error values
- `as` aliases for imports, catch and function parameters
- `destroy()` to turn objects into arguments
- Built-in libraries (no install needed): http, fs, Json, exec
- Libraries can have a main `.cjy` file
- Improved import/export
- CLI: update, remove, start, exec
- New package.json model with mainScript, links, dependences, scripts
- range() from 0 to x
- len() builtin
- Expanded error codes (ERR001–ERR040)
- Better terminal interface

## 1.2.1
- range, len, more errors, CLI improvements

## 1.1.0
- AST-based parser foundation, logos, error table
